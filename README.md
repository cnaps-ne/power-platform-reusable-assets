# Power Platform Reusable Assets

A curated public library of generic SharePoint formatting and Canvas Power Apps snippets for request, incident, work-queue, change and delivery-management solutions.

This repository contains no tenant-specific URLs, IDs, credentials, branding, business rules or internal schemas. It is deliberately independent of any implementation repository.

## Start here

- `docs/REV1-RECOMMENDATIONS.md` — fastest useful subset for a one-week first release.
- `references/CATALOGUE.md` — copied, adapted and reference-only assets with provenance.
- `sharepoint/README.md` — expected internal columns and installation notes.
- `power-apps/README.md` — paste-code workflow, dependencies and import risks.
- `THIRD_PARTY_NOTICES.md` — licences and attribution.
