# Work Queue views

- `operational-view.json`: compact six-column operator view with overdue row emphasis.
- `card-view.json`: tiles/board-style option for lower-volume triage.
- `my-requests-view.json`: requester-friendly list. Create a SharePoint view filter where **SubmittedBy is equal to [Me]**; JSON formatting does not perform filtering or provide security.

The operational view is the Rev 1 default. The card view is optional and is not a true drag-and-drop Kanban board.
